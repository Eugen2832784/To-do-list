# To-do list CLI

![CI](https://github.com/Eugen2832784/To-do-list/actions/workflows/ci.yml/badge.svg)

Простой менеджер задач для терминала, написанный на Go. Без внешних зависимостей, задачи хранятся в локальном JSON-файле.

## Возможности

- Добавление, просмотр, выполнение и удаление задач
- Хранение в читаемом файле `tasks.json`
- Только стандартная библиотека Go

## Установка

Нужен Go 1.21 или новее.

```bash
git clone git@github.com:Eugen2832784/To-do-list.git
cd To-do-list
go build -o todo .
```

Чтобы запускать просто `todo` из любой папки:

```bash
go install .
```

Бинарник появится в `$(go env GOPATH)/bin`. Если этой папки нет в `PATH`, добавь в `~/.zshrc` строку `export PATH="$PATH:$(go env GOPATH)/bin"`.

## Использование

```bash
./todo add "Купить молоко"
./todo list
./todo done 1
./todo delete 1
```

Пример сессии:

```
$ ./todo add "Купить молоко"
Добавлено: Купить молоко

$ ./todo add "Написать тесты на Go"
Добавлено: Написать тесты на Go

$ ./todo list
1. [ ] Купить молоко
2. [ ] Написать тесты на Go

$ ./todo done 2
Выполнено: Написать тесты на Go

$ ./todo list
1. [ ] Купить молоко
2. [x] Написать тесты на Go
```

### Команды

| Команда | Описание |
|---------|----------|
| `add "текст"` | Добавить новую задачу |
| `list` | Показать все задачи |
| `list --todo` | Только невыполненные |
| `list --done` | Только выполненные |
| `done <id>` | Отметить задачу выполненной |
| `delete <id>` | Удалить задачу |
| `clear` | Удалить все задачи |

## Где хранятся данные

Задачи хранятся в файле `~/.todo/tasks.json` в домашней папке, поэтому список один и тот же, откуда бы ты ни запустил программу. Папка создаётся автоматически.

Свой путь можно задать переменной окружения:

```bash
TODO_FILE=/path/to/my-tasks.json ./todo list
```
