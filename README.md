# To-do list CLI

Простой менеджер задач для терминала, написанный на Go. Без внешних зависимостей, задачи хранятся в локальном JSON-файле.

## Возможности

- Добавление, просмотр, выполнение и удаление задач
- Хранение в читаемом файле `tasks.json`
- Только стандартная библиотека Go

## Установка

Нужен Go 1.21 или новее.

```bash
git clone git@github.com:Eugen2832784/To-do-list.git
cd To-do-list
go build -o todo .
```

## Использование

```bash
./todo add "Купить молоко"
./todo list
./todo done 1
./todo delete 1
```

Пример сессии:

```
$ ./todo add "Купить молоко"
Добавлено: Купить молоко

$ ./todo add "Написать тесты на Go"
Добавлено: Написать тесты на Go

$ ./todo list
1. [ ] Купить молоко
2. [ ] Написать тесты на Go

$ ./todo done 2
Выполнено: Написать тесты на Go

$ ./todo list
1. [ ] Купить молоко
2. [x] Написать тесты на Go
```

### Команды

| Команда | Описание |
|---------|----------|
| `add "текст"` | Добавить новую задачу |
| `list` | Показать все задачи |
| `done <id>` | Отметить задачу выполненной |
| `delete <id>` | Удалить задачу |

## Где хранятся данные

Задачи сохраняются в файле `tasks.json` в той папке, из которой запущена программа.

## Структура проекта

```
.
├── main.go                  # точка входа
└── internal/
    ├── task/                # тип Task, NextID, FindIndex
    ├── storage/             # чтение и запись tasks.json
    └── cli/                 # разбор и выполнение команд
```
